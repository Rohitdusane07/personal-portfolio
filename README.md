## 📖 Overview

Welcome to my personal 3D interactive developer portfolio! Built with **React 18**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**, this portfolio provides a modern, immersive web experience featuring interactive 3D visual elements, custom section avatars, dark/light cyber-themed aesthetics, and a direct serverless contact pipeline.

---

## ✨ Key Features

- **🎭 Interactive Section Avatars:** 8 curated photo avatars with custom background cutouts tailored specifically to each section (About, Tech Stack, Featured Projects, What I Do, Currently Learning, Experience, Personality, and Contact).
- **🌓 Dual Theme Experience:** Seamless dark (Cyberpunk Neon Cyan) and light (Rose Gold Warm Glow) modes powered by Tailwind and CSS variable context.
- **📱 Responsive Layout:** Optimized for all screen sizes. Features custom responsive ordering where mobile view elegantly presents *Section Heading ➔ Avatar Photo ➔ Content Cards*.
- **⚡ High Performance:** Lightning-fast page loads and zero-latency client-side transitions powered by Vite.
- **📬 Zero-Backend Direct Contact Form:** Direct email delivery to `rohitdusane.engineer@gmail.com` powered by FormSubmit.co via AJAX with spam protection tokens and instant user feedback.
- **🔍 Project Deep-Dives:** Interactive modals and category filtering for exploring architecture, key contributions, and GitHub repositories.

## 🛠️ Tech Stack

### Frontend & UI
- **Framework:** React 18 (TypeScript)
- **Bundler:** Vite
- **Styling:** Tailwind CSS, PostCSS
- **Animations:** Framer Motion
- **Icons:** Lucide React, React Icons

### 3D & Graphics
- **Three.js** / `@react-three/fiber`
- Custom SVG vector art and dynamic mesh glows

### Form & Integrations
- **FormSubmit.co** (Secure serverless email delivery)

1. **Install dependencies:**
   ```bash
   pnpm install
   # or
   npm install
   ```

2. **Start the development server:**
   ```bash
   pnpm run dev
   # or
   npm run dev
   ```

3. **Open your browser:**
   Navigate to `http://localhost:5000` to view the portfolio.
